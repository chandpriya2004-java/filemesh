
# FileMesh

**Distributed Cloud File Storage & Secure File Sharing System**

FileMesh is a file storage system where users can upload, download, manage, and securely share their files.

## Tech Stack

* **Backend:** Java, Spring Boot
* **Frontend:** Next.js, React
* **Database:** MySQL
* **Storage:** Cloudflare R2
* **Authentication:** Spring Security, JWT

## Features

* User authentication
* File upload & download
* File management
* Secure file sharing
* Public share links
* Cloud object storage
* Distributed storage support
